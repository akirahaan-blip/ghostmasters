📝 記録のしかた

  1. その日の DAY をタップして開く（前回の続きの日は最初から開いています）
  2. リサーチの「＋ポケモンを追加」を押す → ポケモンのボタンが並びます
  3. 出たポケモンのボタンを押す。2体なら2回押します（緑＝加点、赤＝減点）
  4. 色違いがいたら、その行の「★色違い」を押す（点数が2倍）
  5. シルフスコープを使ったら「🔍 シルフスコープを使う」にチェック。イベント中1回だけです

点数と内訳は自動で計算されます。いちばん高い点数は、画面上の「★ ベストスコア」にいつも出ています。まちがえたポケモンは「✕」で消せます。

📤 X に投稿するとき

  1. 「ファイルを選択」でリサーチのスクショを選ぶ
  2. 「📷 投稿用画像を作る」→ スクショの下に点数が付いた画像ができます
  3. 「📤 保存・共有する」→ 出てきたアプリの中から「X」を選ぶ
  4. X の投稿欄に、画像と投稿文（#ゴーストマスターズ・点数・ポケモン）が入るので、そのまま投稿

投稿文が入っていなかったときは、投稿欄を長押しして「ペースト」を押してください（「保存・共有する」を押したときにコピーされています）。画像だけ取っておきたいときは、X の代わりに「画像を保存」を選ぶと写真アプリに入ります。

📱 ホーム画面に追加（アプリのように使う）

iPhone（Safari）

  1. Safari でこのページを開く（X の中で開いている場合は、先に開き直す）
  2. 画面下の 共有ボタン（四角から上向きの矢印）を押す
  3. メニューを下へ動かして「ホーム画面に追加」を押す
  4. 右上の「追加」を押す → ホーム画面にムウマのアイコンが出ます

iPhone（Chrome）

  1. Chrome でこのページを開く
  2. アドレス欄の右の 共有ボタン（四角から上向きの矢印）を押す
  3. 「ホーム画面に追加」→「追加」

Android（Chrome）

  1. Chrome でこのページを開く
  2. 右上の「︙」を押す
  3. 「ホーム画面に追加」を押して「追加」

⚠ iPhone では、ホーム画面のアイコンから開くと、Safari や Chrome で入れた記録が出ないことがあります（記録の保存場所が別になるため）。ホーム画面に追加したら、そのあとはアイコンから使うのがおすすめです。追加するときに「Webアプリとして開く」が出たらオフにすると、ブラウザと同じ記録を使えます。

⚠ 注意

  • 記録はこの端末のこのブラウザの中だけに保存されます。他の端末やブラウザでは見られません
  • ブラウザの「履歴とWebサイトデータを消去」をすると、記録も消えます
  • X などのアプリの中で開くと、記録が消えることがあります。Safari や Chrome で開いて、ホーム画面に追加して使ってください
  • 写真は保存されません。ページを開き直したら、もう一度選んでください
