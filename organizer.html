📋 スコア集計のしかた（主催者の方へ）

ゴーストマスターズ スコア記録ツール ／ Googleフォームで提出を受け付けて、自動で順位を出します

しくみ

① 参加者が、スコア記録ツールでリサーチの点数を計算する
② 参加者が、X に投稿する（今までどおり）
③ 参加者が、ツールの「🏆 スコアを提出」を押す → 点数などが入力済みの Googleフォームが開く → 投稿のURLを貼って送信
④ 回答が Googleスプレッドシートに自動でたまる
⑤ 主催者は、表で 1人ずつの最高点と順位を見る。上位の人だけ、投稿のURLからスクショを確かめる

お金はかかりません。用意するのは Googleアカウントだけです。参加者は Googleアカウントがなくても提出できます。

① Googleフォームを作る

  1. パソコンのブラウザで forms.google.com を開いて、Googleアカウントでログインする
  2. 「空白のフォーム」（大きな「＋」）を押す
  3. いちばん上の「無題のフォーム」を押して、「ゴーストマスターズ スコア提出」のように書きかえる

② 質問を7つ作る

次の表の上から順番に作ってください。どれも種類は「記述式」です（質問の右にある種類の欄で選びます）。右下の「必須」はオンにしてください。

順番質問の名前メモ
1X のID
2DAY
3リサーチ①か②が入ります
4点数質問の右下の「︙」→「回答の検証」→「数値」を選ぶ（順位を正しく並べるため）
5出たポケモン
6シルフスコープ「使用」か「なし」が入ります
7X の投稿のURL参加者が自分で貼ります

質問を足すときは、右側に出ている「⊕（質問を追加）」を押します。

③ 設定を確かめる

  1. 画面の上の「設定」タブを押す
  2. 「回答」の項目を開く
  3. 「メールアドレスを収集する」が「収集しない」になっているか確かめる
  4. 「回答を1回に制限する」がオフになっているか確かめる（オンだと、参加者に Googleのログインが必要になり、リサーチごとに出せなくなります）

④ 「事前入力したURL」をツールの作者に送る

ツールの「🏆 スコアを提出」ボタンとフォームをつなぐために、フォームの質問の番号が必要です。次の手順で作ったリンクを、ツールの作者に送ってください。

  1. フォームの編集画面の右上の「︙」を押す
  2. 「事前入力した URL を取得」を押す → 回答の見本を入れる画面が開きます
  3. 質問1〜6に、質問の順番の数字を入れる（X のID に「1」、DAY に「2」…、シルフスコープに「6」）。質問7は空のままで大丈夫です
  4. いちばん下の「リンクを取得」→「リンクをコピー」を押す
  5. コピーしたリンクを、ツールの作者に送る（X のDM など）
作者がこのリンクをツールに入れると、参加者の「🏆 スコアを提出」ボタンが使えるようになります。それまでは、ボタンを押すと「まだ設定されていません」と出ます。

⑤ 回答をスプレッドシートにためる

  1. フォームの編集画面の上の「回答」タブを押す
  2. 「スプレッドシートにリンク」（緑の表のマーク）を押す
  3. 「新しいスプレッドシートを作成」を選んで「作成」を押す → 回答がたまっていく表が開きます

表の下の見出しが「フォームの回答 1」になっていることを確かめてください（下の式はこの名前を使っています）。

⑥ 自動で順位を出す表を作る

（1）1人ずつの最高点の順位

  1. 表の左下の「＋」を押して、新しいシートを足す
  2. 新しいシートの見出しを右クリック →「名前を変更」→「ランキング」
  3. いちばん左上のマス（A1）を押して、下の式を貼り付けて Enter
=QUERY('フォームの回答 1'!B:E,"select B, max(E) where B is not null group by B order by max(E) desc label B 'XのID', max(E) '最高点'",1)

→ 1人ずつのいちばん高い点数が、高い順に並びます。新しい提出があると、自動で並び直ります。

（2）すべての提出を点数の高い順に並べる（スクショの確認用）

  1. もう一度「＋」でシートを足して、名前を「高い順」にする
  2. A1 に下の式を貼り付けて Enter
=SORT(FILTER('フォームの回答 1'!B2:H,'フォームの回答 1'!B2:B<>""),4,FALSE)

→ 提出が点数の高い順に並び、いちばん右の列に X の投稿のURL が出ます。押すと投稿が開くので、上位の人のスクショを確かめられます。

⑦ 大会が終わったら

  1. 「ランキング」シートで順位を見る
  2. 上位の人を「高い順」シートで探して、投稿のURLからスクショと点数が合っているか確かめる
  3. フォームの「回答」タブの「回答を受付中」をオフにすると、提出を締め切れます

知っておくと安心なこと

  • 参加者はリサーチごとに何回でも提出できます。最高点は表で自動で出るので、同じ人の提出が何件あっても大丈夫です
  • まちがえて出した人は、正しい内容でもう一度出せば大丈夫です。ただし最高点で数えるので、まちがえて高い点数を出した場合は、主催者が表の「フォームの回答 1」でその行を消してください
  • X のIDは、ツールが「@」を付けて、空白を消して、小文字にそろえて送ります。同じ人が別の人として数えられにくくしています
  • 点数は参加者の自己申告です。上位の人だけ投稿のスクショで確かめるのがおすすめです
点数の計算は、ツールが大会のルール（色違い・種族ボーナス・シルフスコープ・カラカラ）どおりに自動で行います。ルールが変わるときは、大会の前にツールの作者に伝えてください。
